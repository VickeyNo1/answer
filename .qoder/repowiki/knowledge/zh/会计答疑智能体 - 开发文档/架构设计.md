文档定义了一个双端分离项目：后端 `backend/` 基于 FastAPI，按功能拆分为 `auth`（JWT 登录）、`chat`（对话+RAG+SSE 流式）、`knowledge`（PDF/Word/TXT 解析→text-embedding-v3 向量化→ChromaDB 检索）、`admin`（学生 CRUD + 统计），通过 `app/main.py` 注册路由并启动时调用 `database.py` 建表；SQLite 与 ChromaDB 均为嵌入式持久化于 `data/` 目录。前端 `frontend/` 使用 Next.js App Router，页面位于 `src/app/{login,admin}`，组件集中在 `src/components`，API 封装在 `lib/api.ts` 并通过 JWT 拦截器附加认证头。数据流向为浏览器 → FastAPI(8000) → SQLite/ChromaDB 本地存储 + HTTPS:443 调用 dashscope.aliyuncs.com 的 qwen-plus 和 text-embedding-v3。环境变量统一由 `pydantic-settings` 从 `.env` 读取，依赖管理采用 uv（`uv init --python 3.11` + `uv venv` + `uv run`）。

后端必须使用 uv 初始化：`cd backend && uv init --python 3.11 && uv venv && .\.venv\Scripts\Activate.ps1 && uv pip install -r requirements.txt`，运行命令为 `uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`；初始管理员账号由 `seed.py` 创建（默认 admin/admin123）。前端 `cd frontend && npm install && npm run dev` 启动 3000 端口。生产部署推荐 Docker 或 Nginx 反向代理 + HTTPS。

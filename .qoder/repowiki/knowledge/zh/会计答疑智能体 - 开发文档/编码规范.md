- 后端模块按领域划分子包（auth/chat/knowledge/admin），每个子包包含 router.py（路由）、service 文件（业务逻辑）及可选 deps/memory 等辅助模块，入口统一由 main.py 挂载。
- 配置项集中定义在 config.py 的 Settings 类中，通过 pydantic-settings 从 .env 加载并以 @lru_cache 缓存单例，避免重复读取。
- Pydantic 模型按领域分组（LoginRequest/TokenResponse、ConversationCreate/MessageOut、StudentCreate/StatsResponse 等），请求与响应类型一一对应，便于 API 自动文档生成。
- 所有需要认证的接口通过 FastAPI 依赖注入（auth/deps.py）获取当前用户，管理员接口额外校验 role == 'admin'。
- RAG 流程固定为：用户消息入库 → 加载最近 10 条历史 → embedding 向量化 → ChromaDB Top-5 检索 → 组装 System Prompt + History + User → qwen-plus stream=True → SSE 逐块返回。

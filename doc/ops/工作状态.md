## 新电脑上手步骤

1. `git clone git@github.com:VickeyNo1/answer.git`
2. 创建 `backend/.env`（**含密钥不入库**，从旧电脑安全拷贝，或按 [部署文档](部署文档.md) 模板重填）
3. 后端：`cd backend && uv sync`；前端：`cd frontend && npm install`
4. 本地开发注意：本地能否直连机器A MySQL 取决于宽带出口 IP 是否固定——**主力 Windows 机出口 IP 已加安全组+MySQL 用户白名单可直连**（真实出口 IP 以 MySQL 1130 报错为准，网页测的 IP 可能是代理不可信）；**CGNAT 宽带（出口 IP 漂移）的电脑不可直连**，需走 SSH 隧道或在机器B 上调试

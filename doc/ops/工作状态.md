## 新电脑上手步骤

1. `git clone git@github.com:VickeyNo1/answer.git`
2. 创建 `backend/.env`（**含密钥不入库**，从旧电脑安全拷贝，或按 [部署文档](部署文档.md) 模板重填）
3. 后端：`cd backend && uv sync`；前端：`cd frontend && npm install`
4. 本地开发注意：**本地宽带是 CGNAT（出口 IP 漂移），无法直连机器A MySQL**（安全组白名单方案不可行）。本地要连库需走 SSH 隧道或在机器B 上调试

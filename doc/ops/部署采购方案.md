## 三、各项采购详情

### 3.1 云服务器

#### 应用服务器（必须）

用于部署系统后端程序和前端页面，处理用户请求、对话管理、知识库检索等核心业务。

| 配置项 | 规格 |
|--------|------|
| CPU | 4 核 |
| 内存 | 8 GB |
| 系统盘 | 50 GB SSD |
| 带宽 | 5 - 10 Mbps |
| 操作系统 | Linux (Ubuntu / CentOS) |

**推荐选购：** 阿里云 ECS / 腾讯云 CVM，选择包年包月更优惠。

| 云厂商 | 参考价格 | 购买方式 |
|--------|----------|----------|
| 阿里云 ECS（4核8G） | ≈ 3,500 - 4,500 元/年 | 包年 |
| 腾讯云 CVM（4核8G） | ≈ 3,200 - 4,000 元/年 | 包年 |

> **预估费用：约 4,000 元/年**

#### 数据沙箱服务器（可选，用于改善体验）

用于大模型处理数据时的隔离运行环境，可执行代码验证、数据处理等任务，提升回答的准确性和丰富度。非核心必需，但能显著改善 AI 回答质量（例如 AI 可以运行会计计算代码来验证答案）。

| 配置项 | 规格 |
|--------|------|
| CPU | 4 核 |
| 内存 | 8 GB |
| 系统盘 | 50 GB SSD |
| 带宽 | 3 - 5 Mbps |

> **预估费用：约 4,000 元/年**
>
> **建议：** 初期可不开启此服务，待系统运行稳定后根据需求再决定是否增加。

### 3.2 云存储

#### 关系型数据库（必须）

存储用户账号、对话记录、消息历史、系统配置等结构化数据。推荐使用云厂商托管的数据库服务，免运维、自动备份、高可用。

| 配置项 | 规格 |
|--------|------|
| 产品类型 | 阿里云 RDS MySQL / 腾讯云 TDSQL |
| 存储空间 | 100 GB（高性能 SSD） |
| 规格 | 1核2G 起步即可（数据量不大） |

| 云厂商 | 参考价格 | 购买方式 |
|--------|----------|----------|
| 阿里云 RDS MySQL（100G） | ≈ 2,500 - 3,500 元/年 | 包年 |
| 腾讯云 MySQL（100G） | ≈ 2,800 - 3,200 元/年 | 包年 |

> **预估费用：约 3,000 元/年**
>
> **节省方案：** 初期用户量较少时，可先使用应用服务器自带的 SQLite 嵌入式数据库（免费），待用户量增长后再迁移至云数据库。

#### 对象存储 OSS（必须）

用于存储大文件：用户上传的PDF、Word 文档、系统运行日志、备份数据等。

| 计费项 | 参考价格 |

| 存储费 | ≈ 0.12 元/GB/月 |
| 外网流量 | ≈ 0.25 元/GB |

> **预估费用：约 1,200 元/年**（含存储 + 适量下载流量）

### 3.3 大模型 API 服务（核心开支）

这是系统运行的核心能力——AI 理解和处理问题。推荐采用 **API 按量付费** 方式，无需购买昂贵的 GPU 硬件。

#### 方案对比：API 调用 vs 自部署

| 对比项 | API 按量付费（推荐） | 自建 GPU 部署 |
|--------|---------------------|--------------|
| 初始投入 | 0 元，充值即用     | GPU 硬件约 12 万元起 |
| 硬件采购 | 无需              | RTX A6000 48G ≈ 12 万元 |
| 可部署模型 | 可选多家最强模型 | 仅能部署低配版开源模型 |
| 回答质量 | 可使用最先进模型 | 受限于硬件，只能跑小模型 |
| 运维成本 | 零运维 | 需专业人员维护 GPU 服务器 |
| 适用场景 | 绝大多数场景 | 仅适用于数据高度保密、隐私要求极高的场景 |

**结论：强烈推荐使用 API 按量付费方案。** 自部署 GPU 方案投入大（12万+）、只能运行低配模型，且需要专业运维人员，性价比极低。除非有极高的数据保密需求，否则不建议自部署。

以下为各厂商主力模型的最新定价（2026年7月），单位均为 **元/百万 Token**：

### 3.4 专业知识库建设

AI 回答的质量直接取决于知识库中专业资料的丰富度和准确性。系统采用 RAG（检索增强生成）技术，将专业教材和资料存入向量数据库，AI 回答问题时自动检索最相关的段落作为参考。

#### 知识库建设内容

| 工作内容 | 说明 | 负责方 |
|----------|------|--------|
| 收集整理专业教材 | 会计基础、中级财务会计、高级会计、审计学、税法等教材的 PDF/Word 电子版 | 校方/客户 |
| 整理课件与习题 | 教师课件 PPT、历年真题、练习题及标准答案 | 校方/客户 |
| 知识校对审核 | 确保上传资料内容准确无误，避免 AI 给出错误回答 | 校方/客户 |
| 系统上传入库 | 将文档上传至系统，自动完成解析、切分、向量化 | 系统自动（管理员操作） |
| 持续更新维护 | 根据教材修订、政策变化定期更新知识库内容 | 校方/客户 |

#### 知识库维护成本

| 项目 | 费用 |
|------|------|
| 文档上传与向量化 | 包含在 API 费用中（Embedding 费用极低） |
| 向量数据库运行 | 嵌入式部署在应用服务器中，无额外费用 |
| 人工整理维护 | 取决于校方投入的人力资源，建议安排 1 名教师兼职负责 |

> **重要提示：** 知识库的质量是系统回答质量的关键。建议初期至少上传 **5-10 本** 核心教材和课件，覆盖主要会计课程。后续根据学生反馈持续补充。

## 六、采购建议

### 6.1 推荐云厂商

| 服务 | 推荐 | 备选 |
|------|------|------|
| 云服务器 | 阿里云 ECS | 腾讯云 CVM |
| 云数据库 | 阿里云 RDS MySQL | 腾讯云 TDSQL |
| 对象存储 | 阿里云 OSS | 腾讯云 COS |
| 大模型 API | 阿里云百炼（千问系列） | DeepSeek / 智谱 AI |

> **建议选择同一家云厂商** 采购服务器、数据库和存储，可享受内网互通（速度快、无流量费）和打包优惠。

### 6.2 分阶段采购策略

```
第 1 阶段：试运行（第 1-3 个月）
├── 采购：应用服务器 + OSS + 大模型 API（充值 2,000 元先用）
├── 目标：小范围试用，验证效果
└── 费用：约 5,000 - 8,000 元

第 2 阶段：正式运行（第 4-12 个月）
├── 采购：补充云数据库 RDS，大模型 API 持续充值
├── 目标：全面开放使用
└── 费用：按实际用量充值

第 3 阶段：优化扩展（视需要）
├── 采购：增加沙箱服务器、升级配置
├── 目标：提升 AI 回答质量
└── 费用：按需增加
```

### 6.3 注意事项

1. **大模型 API 费用为主要变量**：其他费用相对固定，API 费用随使用量线性增长。建议初期小额充值，根据实际消耗调整。
2. **包年更划算**：服务器、数据库等固定资源选包年包月，通常比按月购买便宜 30%-50%。
3. **关注促销活动**：各云厂商定期有促销活动（如阿里云 618、双 11），可趁机采购。
4. **数据备份**：建议定期导出数据库备份文件至 OSS，防止数据丢失。
5. **知识库是核心竞争力**：AI 回答质量 80% 取决于知识库质量，建议投入足够精力整理专业资料。

## 七、常见问题

**Q：为什么不自己买 GPU 服务器部署大模型？**

一块 RTX A6000 48G 显卡目前市场价约 12 万元，且只能部署低配版开源模型（如 DeepSeek 的轻量版本），回答质量远不如直接调用千问、DeepSeek 等商用 API。API 按量付费模式下，每年仅需几千到几万元即可使用最先进的模型，性价比远高于自部署。除非有极高的数据保密要求（如涉密数据不能出网），否则不建议自部署。

**Q：如果用户量增长到 500 人以上怎么办？**

系统支持水平扩展：升级服务器配置（如 8核16G）或增加服务器数量，大模型 API 天然支持高并发，无需额外部署。云数据库和 OSS 也支持在线扩容。

**Q：大模型 API 会不会突然涨价？**

目前大模型 API 处于激烈竞争期，整体趋势是降价而非涨价。且我们可以随时切换到其他厂商的模型（系统支持多模型适配），不会被单一厂商绑定。

**Q：知识库的教材有版权问题吗？**

建议使用学校已购买版权的教材和内部课件。系统仅将教材内容用于本校学生的教学答疑，属于合理使用范围。如有疑虑，建议咨询学校法务部门。

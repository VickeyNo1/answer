## 一、项目概述

### 1.1 项目目标

构建一个面向会计专业学生的智能答疑系统，基于通义千问大模型 + RAG 知识库检索，提供准确的会计专业问题解答。

### 1.2 核心功能

- 学生登录身份识别（学号+密码）
- AI 对话答疑（流式输出，支持多轮对话记忆）
- 知识库管理（上传会计教材/课件，自动向量化检索）
- 管理员后台（学生管理、知识库管理、使用统计）

### 1.3 技术选型

| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 前端框架 | Next.js (App Router) | 16.2.10 | React 全栈框架 |
| UI 库 | React | 19.2.4 | — |
| 前端样式 | Tailwind CSS | v4 | 原子化 CSS |
| 后端框架 | Python FastAPI | 0.115.* | 异步高性能 Web 框架 |
| 数据库 | SQLite（WAL） | 3 (内置) | 嵌入式轻量数据库，零运维 |
| 向量数据库 | ChromaDB | 0.5.* | 嵌入式向量数据库（cosine） |
| 大模型 | 通义千问 + DeepSeek | dashscope SDK 1.20.* | 对话生成，可在后台配置/切换（v2.0） |
| Embedding 模型 | text-embedding-v3 | dashscope SDK | 文本向量化 |
| 认证方案 | JWT | python-jose | 无状态令牌认证 |
| 密码加密 | bcrypt | passlib | 安全哈希 |
| 虚拟环境 | uv | 最新 | Python 3.11+ 包管理与虚拟环境 |

> DeepSeek（deepseek-v3/r1）走**阿里百炼统一接入**，复用 `DASHSCOPE_API_KEY`，模型名直接通过 dashscope `Generation.call` 调用，无需独立 SDK 或分支。

## 二、开发环境规范

### 2.1 uv 虚拟环境管理

**规则：所有后端开发和包安装必须严格在 uv 管理的虚拟环境中进行。**

#### 初始化步骤

```bash
# 进入后端目录
cd d:\code\answer\backend

# 用 uv 初始化 Python 项目
uv init --python 3.11

# 创建虚拟环境 (.venv 目录)
uv venv

# 激活虚拟环境 (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# 安装依赖
uv pip install -r requirements.txt

# 添加新依赖
uv pip install <package_name>
uv pip freeze > requirements.txt
```

#### 运行规范

```bash
# 启动后端 (通过 uv run)
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 运行脚本
uv run python seed.py
```

#### 版本控制

- `.venv/` 目录加入 `.gitignore`
- `pyproject.toml` + `uv.lock` 纳入版本控制
- `requirements.txt` 作为辅助导出文件

### 2.2 前端环境

```bash
cd d:\code\answer\frontend
```

## 三、端口规划

| 端口 | 服务 | 协议 | 传输数据 |
|------|------|------|----------|
| 8000 | FastAPI 后端 | HTTP/REST | JWT 认证、学生 CRUD、对话 CRUD、知识库管理 |
| 8000 | FastAPI 后端 | HTTP/SSE | 对话流式接口，用户提问 → AI 逐块回答 |
| 3000 | Next.js 前端 | HTTP | 页面渲染、静态资源 |
| 443 | 通义千问对话 API | HTTPS | API Key + 上下文 → 生成文本 |
| 443 | 通义千问 Embedding API | HTTPS | 文本片段 → 1024 维向量 |

### 数据流向

```
浏览器 (localhost:3000)
  │
  ├─ HTTP REST ──→ FastAPI (localhost:8000)
  │                  ├─ SQLite     (./data/app.db，嵌入式，无端口)
  │                  ├─ ChromaDB   (./data/chroma_db，嵌入式，无端口)
  │                  ├─ HTTPS:443 → dashscope.aliyuncs.com (qwen-plus)
  │                  └─ HTTPS:443 → dashscope.aliyuncs.com (text-embedding-v3)
  │
  └─ HTTP SSE ───→ FastAPI (localhost:8000/api/chat)
                    流式逐块返回 AI 回答
```

## 四、数据库设计

### 4.1 表结构 (SQLite)

数据库文件：`backend/data/app.db`

#### users 表（用户）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 用户 ID |
| student_id | TEXT | UNIQUE NOT NULL | 学号（登录账号） |
| password_hash | TEXT | NOT NULL | bcrypt 加密密码 |
| name | TEXT | NOT NULL | 姓名 |
| role | TEXT | DEFAULT 'student' | 角色：student / admin |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

#### conversations 表（对话）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 对话 ID |
| user_id | INTEGER | NOT NULL, FK → users.id | 所属用户 |
| title | TEXT | DEFAULT '新对话' | 对话标题 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

#### messages 表（消息）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 消息 ID |
| conversation_id | INTEGER | NOT NULL, FK → conversations.id | 所属对话 |
| role | TEXT | NOT NULL | 消息角色：user / assistant |
| content | TEXT | NOT NULL | 消息内容 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

#### v2.0 新增表与迁移

- `conversations` 轻量迁移新增列 `subject_id INTEGER`（可空，0=未分类）。
- 新增 3 张表 `model_configs`、`usage_logs`、`subjects`。完整字段以 `app/database.py` 建表 SQL 为准，概览见 [`AGENTS.md` §7](../AGENTS.md#7-数据库表结构)。

| 表 | 用途 | 关键列 |
|----|------|--------|
| `model_configs` | 大模型配置 | `provider, model_name(UNIQUE), price_in, price_out, enabled, is_active` |
| `usage_logs` | 用量与费用 | `model_name, prompt_tokens, completion_tokens, total_tokens, cost` |
| `subjects` | 科目 | `name(UNIQUE), category('general'/'professional'), sort_order` |

### 4.2 建表 SQL

```sql
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    name TEXT NOT NULL,
    role TEXT DEFAULT 'student',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS conversations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    title TEXT DEFAULT '新对话',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE TABLE IF NOT EXISTS messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    conversation_id INTEGER NOT NULL,
    role TEXT NOT NULL,
    content TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (conversation_id) REFERENCES conversations(id)
);
```

### 5.3 核心模块说明

#### 5.3.1 main.py - FastAPI 入口

- 创建 FastAPI 应用实例
- 配置 CORS 中间件（允许前端 3000 端口跨域）
- 注册所有路由模块：auth、chat、knowledge、admin
- 启动时调用 database.py 自动建表
- 挂载静态文件目录 (uploads)

#### 5.3.2 config.py - 配置管理

- 使用 `pydantic-settings` 读取 `.env` 文件
- 定义 `Settings` 类，包含所有配置项
- 通过 `@lru_cache` 缓存配置单例

#### 5.3.3 database.py - 数据库

- 使用 Python 内置 `sqlite3` 模块
- `get_db()` 函数返回数据库连接（FastAPI 依赖注入）
- `init_db()` 函数执行建表 SQL（启动时调用）
- 启用 WAL 模式提升并发读写性能

#### 5.3.4 models.py - 数据模型 (Pydantic)

### 8.2 生产环境

- **后端**：Docker 容器或云服务器直接运行 uvicorn (推荐 2核4G)
- **前端**：Vercel 免费部署，或 `next build` 静态导出由 Nginx 托管
- **数据**：SQLite 文件 + ChromaDB 目录随服务器存储
- **备份**：定期导出 `data/app.db` 文件
- **域名**：配置 Nginx 反向代理 + HTTPS 证书

## 一、归因方法（可复现）

1. 把 72 题的检索请求**原样重放**（题干作 query，questions top_k=3 + textbook top_k=8），拿到当时喂给模型的资料全文，用金标准的特征片段量覆盖率；
2. 对覆盖率 <0.2 的 62 题，做**存在性探测**：直接拿金标准原文当 query 搜语料（最强语义探测）——61 题依然搜不到，即语料中不存在该内容；
3. 有效性校验：资料覆盖率与专家得分强相关（覆盖率 ≥0.2 的题中位 85 分 vs <0.2 的 62.5 分）；语料缺失但得高分的题都是参数记忆可答对的经典老考点，自洽。

**结论：检索链路本身没有问题**（72 题的引用全部命中正确章节），缺的是语料里没有这些内容。模型拿不到依据就靠参数记忆作答，遇到**新旧准则冲突**时会整题答反——5 道 0 分题全部是「2026 新解释 vs 模型旧记忆」冲突。

## 二、缺口主题清单（按优先级）

### P0-1｜解释第19号——金融负债终止确认与资本公积结转（最严重，0 分重灾区）

语料中**完全没有**解释第19号的内容，模型全部用旧体系记忆作答。涉及 6 题，其中 3 道 0 分。需要补的规则点：

- **电子支付金融负债在结算日前终止确认的条件**：不可撤回付款指令 + 资金被冻结不能支取用于结算 + 结算风险不重大，三者同时满足；且该会计政策需一致应用（T057、T383、T321）
- **处置同一控制下合并形成的子公司股权时，原合并日形成的资本公积不得转入当期损益或留存收益**（无论交易对手是否关联方）——旧教材「转入投资收益」的口径已被推翻（T385、T323）
- **SPPI 与或有特征**：与基本借贷风险和成本不直接相关的或有特征，应比较**所有可能情景**下现金流与无该特征工具的差异，差异不显著时仍可能满足 SPPI（T113、T386）

### P0-2｜合同挂钩工具（CLI）定义与穿透评估

涉及 8 题（T059 20分、T329 0分、T058、T114、T116、T387、T388、T090）。语料只有「金融资产分类」泛化内容，没有 CLI 的专门定义与判定细则：

- CLI = 具有无追索权特征的金融资产中的**特定子集**：还需存在多个有明确优先劣后顺序的分级，并导致信用风险集中与不成比例分配；**单层无追索权工具不当然属于 CLI**（T059、T329、T389）
- 持有 CLI 还需评估基础资产池：是否包含符合规定的基础工具、本分级承担的基础资产信用风险是否等于或小于基础资产本身（T116、T388）
- 无追索权特征资产的分类需**穿透评估**基础资产/现金流与合同现金流的联系，并考虑次级债务、权益工具等其他安排；基础资产是金融或非金融不决定结论（T058、T114、T387）

### P0-3｜货币可兑换性与即期汇率估计（解释第20号）

涉及 6 题（T332 0分、T334 3.75分、T060、T391、T390、T118），第22章外币折算语料停留在旧口径：

- 可兑换性需基于**特定方向、特定目的**独立评估「取得能力」而非「兑换意图」；反向可兑换不能自动证明正向可兑换（T332、T060、T390）
- 只能取得金额不重大的目标货币时，可能认定缺乏可兑换性（T390）
- 缺乏可兑换性时即期汇率估计的**目标**：反映计量日当前主要经济状况下、市场参与者进行有序兑换交易所采用的汇率；可用符合目标的可观察汇率或其他估计方法，不能机械采用官方汇率（T334、T391、T118）

### P1｜数值计算类：缺「带完整计算过程的例题」（28 分档重灾区，12 题）

教材有准则条文，但缺这类题型的**计算演示语料**，模型只能自行推导、算错就丢一半分。全部 50 分档，共 12 题：

| 考点 | 题号 | 缺的内容 |
|------|------|---------|
| 租赁付款额现值（含变更重估） | T236、T237、T239、T240 | 折现计算过程演示 |
| 摊余成本与实际利息 | T241、T242 | 实际利率摊销表的算例 |
| 长投权益法：抵销未实现利润 | T261~T265（5 题） | 净利润份额调整的完整算例 |
| 股份支付：授予日公允价值与累计费用 | T256、T257、T260 | 分年累计确认的算例 |
| 固定资产折旧（双倍余额/年数总和） | T203、T204 | 各年折旧额序列算例 |

### P2｜其他准则口径（模型多数已能答对，补齐属锦上添花，22 题）

- **债务重组**：2019 修订准则的定义与适用范围，不能沿用旧准则「财务困难」口径；取得资产按修订准则初始计量（T129、T101）
- **收入**：合同变更的前瞻处理（终止原合同+订立新合同）；售后代管安排确认收入的严格条件；含重大融资成分的销售（现金售价确认收入+实际利率法确认利息）（T295、T127、T194、T363）
- **补偿性资产 vs 或有对价**的区分、计量基础与限额（T110、T381、T382、T176）
- **解释第18号**：计入营业成本类科目的分录口径与利润表列示；同类项目不得同时采用两种计量模式（T106、T122）
- **租赁保证金**先按金融工具准则确认计量，再结合租赁准则判断（T297）；租赁变更生效日的重新计量（T186）
- **借款费用**：必要生产活动已开始时资本化起点的判断（T337、T158）
- **持有待售**：除决议与计划外，还需「可立即出售、出售极可能发生」条件（T077）
- 个别分录算例：信用减值损失计提、递延所得税资产确认、退款负债（T141、T171、T153）
